# CLM AAMM Trainer (Cloud-ready)

## Cómo desplegar en Streamlit Cloud
1. Sube **esta carpeta completa** a un repositorio **público** de GitHub.
2. Entra en https://share.streamlit.io → **New app**.
3. Selecciona tu repositorio y el archivo principal `app.py` → **Deploy**.
4. La plataforma instalará `requirements.txt` automáticamente y te dará una **URL pública**.

## Uso básico
- Edita `data/species.csv` con tus especies (cinegéticas, EEI, pescables, CREA, tallas...).
- Sube imágenes en la pestaña “Cargar imágenes y vincular” y enlázalas con las especies.
- En “Modo Quiz” genera preguntas y corrige.
